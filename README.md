## Featured Projects

### [VytalCare — Agentic RAG Health System](https://health-navigator-copy.vercel.app/)
**Agentic AI Health Companion**
- **Description**: FastAPI-based RAG health assistant with a persistent memory architecture, using a deterministic rule-based routing layer for reliable agent decisions over probabilistic LLM control, and semantic vector retrieval for grounded medical context
- **Tech Stack**: FastAPI • Gemini API • LangGraph • Qdrant • Vector Search
- **Impact**: Deployed production system on Vercel with 40% improved medical query relevance and 30% faster response times via caching pipelines

### [Vidhan AI](https://github.com/AdityaPrakash781) — Agentic Legal Workflow Automation System
**Multi-Agent Legal Automation Platform**
- **Description**: Multi-agent backend automating legal drafting, research, and compliance tracking, powered by an NLP + retrieval pipeline using semantic embeddings and vector search, plus a document intelligence pipeline with OCR, classification, and structured indexing for unstructured legal data
- **Tech Stack**: NLP • Vector Search • Workflow Orchestration • REST APIs
- **Impact**: Coordinates task-specific agents (Drafting, Research, Compliance) through a modular orchestration engine with modular REST APIs for agent communication

### [Physics-Informed Spatio-Temporal GNN for Urban Heat Prediction](https://github.com/AdityaPrakash781/PhyRes-PINN-UHI-Diagnostics.git)
**Graph Neural Network for Urban Heat Island Forecasting**
- **Description**: Physics-guided spatio-temporal GNN forecasting next-hour urban air temperature and Heat Island effects across 1,867 spatial nodes, using Dynamic Causal Pruning of graph edges based on wind vector alignment to restrict message passing to physically valid heat-advection paths
- **Tech Stack**: PyTorch • PyTorch Geometric • GeoPandas • ERA5 Climate Data
- **Impact**: Resolved GNN representation collapse via PairNorm and residual connections, reducing training loss by 95% over 40 epochs

### [Touchless UI & Air-Writing Interaction System](https://github.com/AdityaPrakash781/Touchless-UI-and-3D-Drawing.git)
**Gesture-Controlled Desktop Application**
- **Description**: Cross-platform desktop app combining real-time gesture-based media control with air-writing character recognition; uses low-latency hand tracking via MediaPipe, extracting 21 3D landmarks per frame with a custom Kalman Filter for noise reduction, and ensemble/CNN classifiers trained on the HaGRID and EMNIST datasets
- **Tech Stack**: Python • OpenCV • TensorFlow • PyQt6 • MediaPipe
- **Impact**: Achieved 94% gesture classification accuracy with real-time character transcription
